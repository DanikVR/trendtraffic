1
Топбар

Выход в сценарий, автосохранение, живая смета стоимости и главная кнопка «Создать видео» — всегда на одном месте, недоступна пока не выполнен чек-лист.

2
Шаги 1–6

Режим → Аватар → Голос и текст → Видеоряд → Субтитры → Музыка. Нумерация + зелёные галочки показывают прогресс. Секции видны только релевантные: «Второй собеседник» появляется в Диалоге, «Серия» — в Динамичном монтаже.

3
Интерактивное превью

Кадр телефона (9:16) или широкий (16:9). Каждая зона кликабельна: пустая — «Пока не загружено», после выбора сразу показывает содержимое; прозрачный фон — силуэт на шахматке. Субтитры — живой пример прямо в кадре. Для монтажа/диалога — полоса плана с сегментами (какой план дорогой, какой бесплатный).

4
Таймлайн реплик

Существующий DialogueTimeline на всю ширину: дорожки голосов A/B, перетаскивание, резка, привязка медиа. Свойства выбранной реплики (показ, длительность, появление) — строкой под дорожками.

Проверено по коду (origin/main)

Что бэкенд уже умеет, а что нужно доделать — по каждой функции этого экрана.

✓ Фоновая музыка: цикл и обрезка готовы

Во всех трёх склейках трек зациклен и обрезан по длине ролика (stream_loop −1, t = D), громкость в процентах уже принимается (дефолт 20%, потолок 150%). Не хватало только интерфейса — ползунок и «сколько играет» подключаем к готовому. Опция «первые N секунд» — маленькая доводка (t = min(N, D) + затухание).

✓ Медиа длиннее реплики — в Диалоге работает

При выборе видео из Галереи длительность замеряется на фронте и ставится «показ целиком»; после речи медиа держится (сегмент без лица — $0), следующие реплики сдвигаются, мастер-голос сплайсится — губы не плывут.

⚠ Обычный режим: врезки реплик пока не собираются

Бэкенд обычной ветки использует только текст реплик (субтитры) и один зацикленный видеоряд; прикреплённые к репликам фото/видео игнорируются, хотя контролы в UI есть. Доводка: собрать обычный режим через тот же план сегментов, что и диалог.

✓ ElevenLabs: озвучка готова, выбора голоса не было

elevenTTS уже принимает voiceId (Sarah и George по умолчанию, модель multilingual v2). Добавляем: эндпоинт списка голосов вашего аккаунта (GET /ugc/voices, кэш) + прослушивание превью + проброс выбранного голоса в сборку.

✓ Галерея едина по всему сервису

GalleryPicker — один компонент на все блоки: вкладки (TrendFlow · Аудио · Из анализа · Тренды · Hotebook), поиск, загрузка с устройства, мини-плеер аудио. Студия подключает его же — переработаем Галерею, обновится везде разом.

⚠ Заставки до и после — новая функция

В спеке и бэкенде их нет. Добавляем spec.intro / spec.outro + склейка concat с нормализацией к формату кадра (контент заставки не преобразуется). Не выбрали — ролик собирается как раньше.

✓ Режим «Без аватара» — композитор уже есть

Блок «Комментатор» умеет ровно это: дорожка голоса + полноэкранные врезки по репликам (видео cover, фото с Ken Burns и фейдами) + музыка с процентом громкости. Нужна ветка в /ugc/build без HeyGen: базовый видеоряд подкладывается в сегменты без врезок. Цена ролика ≈ только озвучка.

⚠ Верхний слой — один ffmpeg-фильтр

Прозрачный PNG растягивается точно в кадр (пользователь готовил полотно под формат) и кладётся overlay поверх собранного видео, до вжигания субтитров — титры остаются читаемыми. При «Оба формата» — свой PNG на каждый формат.

Принципы для перевода на 108 языков

Правила, по которым переписан словарь — и по которым пишутся все новые строки.

Одна строка — одна мысль

Никакой склейки из кусков («Фон · слева»). Порядок слов в других языках другой — склейка ломает перевод.

Кнопка — глагол, раздел — существительное

«Создать видео», «Распознать речь» / «Аватар», «Видеоряд». Пользователь ищет действие глазами.

Без сокращений и жаргона

«Жен» → «Женский», «батч» → «серия», «плашка» → «подпись на экране», «рендер лица» → «оживление аватара».

ICU-плейсхолдеры и плюрализация

«{n} реплик · {s} сек» — числа только через плейсхолдеры, формы множественного числа отдаёт i18n-библиотека.

Направление — иконкой, не символом

Стрелки «←/→» в строках ломают RTL (арабский, иврит). Пространственный смысл несут миниатюры-диаграммы, текст его дублирует словами.

Ключи словаря

Все строки — в одном файле ugcStrings.ts с ключами вида ugc.avatar.transparent.hint — готовая база для конвейера перевода.

Что ещё можно добавить дёшево

Простые варианты на уже работающем коде. Решение принято: 1, 2, 5, 6, 7 — в работе (уже на макете выше), 3 и 4 — отложены.

1 · Форматы 1:1 и 4:5 ✓ в работе

Instagram-лента и Facebook. Композиторы уже ориентационные — добавить два размера в список форматов. На макете: формат — мультивыбор, первый крупно, остальные миниатюрами.

2 · Выровнять громкость голоса ✓ в работе

Для «своей записи»: нормализация loudnorm одним ffmpeg-фильтром — голос всегда ровный. Тумблер на вкладке «Моя запись», включён по умолчанию.

3 · Обложка ролика отложено

Выбрать кадр из видео или фото из Галереи → первый кадр и превью. Механика обложек в сервисе уже есть (store_cover).

4 · A/B-варианты крючка отложено

ИИ пишет 2–3 разных первых фразы → серия роликов с разными хуками. В «Без аватара» — почти бесплатно.

5 · Полоса прогресса ✓ в работе

Тонкая полоска-таймер сверху кадра — приём удержания TikTok. Один drawbox-фильтр. Тумблер в «Верхнем слое», на превью — живая анимация.

6 · Ролик на нескольких языках ✓ в работе

Claude переводит → ElevenLabs multilingual озвучивает → серия по языкам за прогон. Чипы «Языки ролика» в «Голосе и тексте»; в «Без аватара» цена = озвучка × языки.

7 · Бренд-кит ✓ в работе

Слой + заставки + музыка + стиль субтитров + голос. Кнопка «◆ Бренд-кит» в шапке: «Применить» и «Сохранить текущие настройки».

План внедрения

Бэкенд не меняется: /ugc/build, статусы, форматы и все три ветки уже готовы. Работа — только фронтенд.

1
Каркас студии

Новый UgcStudio.tsx — полноэкранный оверлей вместо модалки 600px. Состояние и UgcSpec не меняются — совместимость со старыми сценариями в graph. Клик по облаку UGC открывает студию.

2
Интерактивное превью

UgcPreview.tsx: чистая функция «спека → кадр». Кликабельные зоны с пустыми состояниями, прозрачный фон шахматкой, живые субтитры, формат и раскладка у превью, полоса плана для монтажа и диалога.

3
Левая панель и словарь

Шесть секций-шагов, «Режим ролика» с миниатюрами. Все строки — в ugcStrings.ts (было→стало по таблице выше) — база для 108 языков.

4
Док таймлайна

DialogueTimeline вниз на всю ширину (компонент prop-driven — переносится без правок), свойства выбранной реплики строкой под дорожками.

5
Готовность и сборка

Чек-лист условий, живая смета, этапы прогресса на превью (из note бэкенда), результат с плеером и «Открыть в Галерее». Музыка: ползунок громкости (бэкенд уже зацикливает и обрезает, дефолт 20%) + опция «первые N секунд» с затуханием. Форматы: + 1:1 и 4:5 в UGC_FORMATS (мультивыбор, композиторы уже ориентационные).

6
Голоса, заставки, режим «Без аватара», слой, языки, бренд

ElevenLabs: GET /ugc/voices + проброс spec.voiceId в готовый elevenTTS. Заставки: spec.intro/outro + concat. Режим «Без аватара»: ветка /ugc/build на базе composeCommentator + loudnorm (spec.loudnorm, по умолчанию вкл). Верхний слой: spec.layers по форматам + overlay перед субтитрами; полоса прогресса — drawbox. Языки: spec.langs — перевод скрипта Claude → TTS multilingual → серия файлов «· EN». Бренд-кит: пресеты тенанта (таблица brand_kits: слой, заставки, музыка, стиль субтитров, голос) + «Применить»/«Сохранить». Врезки медиа у реплик в обычном режиме — через план сегментов, как в диалоге.

7
Полировка

Светлая тема, клавиатура и фокус, узкие экраны (превью сверху, секции снизу), пустые состояния Галереи.

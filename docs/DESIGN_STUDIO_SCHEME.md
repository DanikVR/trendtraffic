# Схема профессионального редактора — дизайн-стандарт TrendTraffic

> Заметка для вики сервиса. Описывает, ПО КАКОЙ СХЕМЕ построена UGC-студия (v2.0.6)
> и почему эта же схема переносится на все остальные разделы: один стиль,
> понятно и правильно везде. Эталонная реализация — `apps/frontend/src/pages/flow/UgcStudio.tsx`.
> Интерактивный макет-референс: `https://app.trendtraffic.pro/design/ugc-studio-design.html`
> (файл `apps/frontend/public/design/ugc-studio-design.html`, см. docs/UGC_AVATARS.md §14).

## 1. Идея в одном абзаце

Сложные рабочие экраны TrendTraffic строятся по схеме профессиональных редакторов —
**CapCut, Canva, Descript**. Пользователь этих сервисов, открыв наш раздел, сразу
понимает, где что: слева настройки, в центре живое превью «как будет на самом деле»,
внизу план/таймлайн, справа сверху — одна главная кнопка. Мы не изобретаем свой
паттерн — мы берём тот, к которому аудитория уже приучена миллионами часов в CapCut,
и применяем его КО ВСЕМ разделам одинаково.

Что взято у каждого референса:

| Референс | Что переняли |
|---|---|
| **CapCut** | полноэкранный редактор поверх приложения; вертикальное превью в реальных пропорциях; нижний таймлайн/полоса плана; субтитры прямо на превью |
| **Canva** | левая колонка секций-карточек (режим → материал → оформление → бренд); пустые слоты-заглушки «кликни — выбери»; бренд-кит как сохраняемый пресет |
| **Descript** | работа с речью как с текстом: реплики — редактируемый список (панель «Реплики»), медиа привязывается К РЕПЛИКЕ, а не к таймкоду |

## 2. Анатомия экрана (5 зон)

Полноэкранный оверлей `position: fixed; inset: 0` поверх приложения (z-index 70),
фон `var(--bg-primary)`, колонка на всю высоту:

```
┌──────────────────────────────────────────────────────────────┐
│ ① Топбар: ← Назад · Название · [Бренд-кит] · 💰цена · [CTA] │
├───────────────────────┬──────────────────────────────────────┤
│ ② Левая колонка      │  ③ Центр — живое превью              │
│  настроек (скролл)    │   кадр в РЕАЛЬНЫХ пропорциях формата │
│  секции-карточки:     │   (9:16 / 16:9 / 1:1 / 4:5),         │
│  Режим ролика         │   субтитры, слой, плашки — как       │
│  Аватар               │   в готовом ролике                   │
│  Голос и текст        │                                      │
│  Видеоряд             ├──────────────────────────────────────┤
│  Субтитры / Музыка    │  ④ Нижний док: полоса плана          │
│  Формат / Слой        │   (сегменты ролика по порядку)       │
│  Языки / Бренд-кит    │                                      │
├───────────────────────┴──────────────────────────────────────┤
│ ⑤ Выдвижные слои: drawer «Реплики» (из дока вверх),         │
│    модалки (Галерея-пикер, бренд-кит) — поверх, закрытие Esc │
└──────────────────────────────────────────────────────────────┘
```

Сетка: `grid-template-columns: minmax(292px, 348px) minmax(0, 1fr)` —
левая колонка фиксированной «читаемой» ширины, всё остальное — превью.

Роли зон (это и есть правило переноса на другие разделы):

1. **Топбар** — навигация назад, идентичность раздела, стоимость операции,
   ОДНА главная CTA справа. Больше в топбаре ничего не живёт.
2. **Левая колонка** — все настройки секциями-карточками сверху вниз в порядке
   принятия решений (что за ролик → из чего → как оформлен → на каких языках).
3. **Центр** — превью, которое НЕ врёт: реальные пропорции, реальные субтитры,
   реальный верхний слой. Пустые места кликабельны.
4. **Нижний док** — временнáя ось: план сегментов, таймлайн, прогресс.
5. **Выдвижные слои** — глубокая работа (реплики, пикеры) не уводит с экрана,
   а выезжает поверх; Esc закрывает верхний слой первым.

## 3. Десять принципов (как применены в UGC-студии)

1. **Превью — это правда (WYSIWYG).** Всё, что настроено, немедленно видно в кадре:
   формат меняет пропорции рамки, субтитры рисуются живым примером из первой реплики,
   PNG-слой ложится поверх, прогресс-бар анимируется. Пользователь не «представляет»
   результат — он его видит.

2. **Пустой слот учит.** Незаполненное место — не ошибка, а приглашение:
   «Пока не загружено» + клик открывает Галерею сразу на нужную цель
   (аватар, видеоряд, заставка, слой). Onboarding без единой инструкции.

3. **Одна главная кнопка + честный чек-лист.** CTA «Собрать» одна, справа в топбаре.
   Пока сборка невозможна — кнопка показывает СПИСОК причин («Готовность к сборке»:
   шаг 1…N, чего не хватает), а не молча серая. Пользователь всегда знает следующий шаг.

4. **Прозрачность цены до клика.** Чип стоимости в топбаре пересчитывается от настроек
   (провайдер, длительность, языки) — никаких сюрпризов после рендера.

5. **Прогрессивное раскрытие.** Секции слева — короткие карточки; глубина
   (редактор реплик с фильтрами по голосам, склейкой, медиа) выезжает drawer-ом
   только когда нужна. Простой сценарий = простой экран.

6. **Одна Галерея на весь сервис.** Любой выбор медиа — из единой Галереи;
   изменение файла там отражается везде. Никаких «локальных» загрузок в разделе.

7. **Слова без жаргона, i18n-first.** Все строки — по-русски понятными словами
   («Режим ролика», «Голос и текст», «Верхний слой»), в словаре i18next
   (`ugc.*`, ~290 ключей) и переводятся на 108 языков. Канон — RU, пивот — EN.
   Ни одной строки, зашитой в компоненте.

8. **Темы из токенов.** Только `var(--…)` из центрального index.css (шрифт Geist,
   акцент — индиго), тёмная тема через класс `.dark` — раздел выглядит
   «родным» в обеих темах автоматически, как панель аналитики.

9. **Свои модалки, предсказуемый Esc.** Никаких `window.confirm` — свои
   ConfirmModal/модалки в стиле сервиса; Esc закрывает слои в порядке
   «верхний первым» (модалка → drawer → студия).

10. **Лучшие практики — как дефолты.** Голос 100% / музыка ~20%, loudnorm-нормализация
    громкости, «музыка первые N сек» с фейдом — правильные значения стоят сразу,
    крутить ползунки не обязательно.

## 4. Где схема уже применена и правило для новых разделов

- **UGC-студия** — эталон схемы (v2.0.6, все 5 зон + 10 принципов).
- **Редактор сценария (MontageEditor)** — полноэкранный редактор, облака-блоки,
  панели поверх; та же логика «настройки → превью → одна CTA».
- **Подкаст-студия, Hotebook, Flow-панель** — секции-карточки, единая Галерея,
  токены темы, свои модалки.
- **Панель аналитики** — источник дизайн-токенов (Geist + индиго, v1.5.7
  «1:1 with analytics panel»), с неё начался единый стиль.

**Правило:** каждый новый рабочий раздел строится по этой схеме и этим принципам —
не «похоже», а по списку из §2–§3. Отклонение от схемы — осознанное решение
с записью причины в PROJECT_NOTES, а не вкусовщина.

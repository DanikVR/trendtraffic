# Hotebook & Google Flow → Галерея: захват результатов через расширение

**Энциклопедия блока.** Как работает перенос готовых работ NotebookLM (Hotebook) и клипов
Google Flow в Галерею TrendTraffic, где что лежит и как это менять/дополнять.
Актуально на app v2.2.40 / расширение v1.3.27 (10.07.2026).

---

## Принцип (решение продукта, 10.07.2026)

**«Работай в сервисе — результаты забираешь по кнопке».**

1. Клик по карточке блокнота в Галерее → открывается **сам NotebookLM** на этом блокноте
   (сохраняя `authuser` рабочей вкладки). Клик по проекту Flow → открывается сам Flow.
2. Пока в сервисе идёт генерация — в приложении крутятся **индикаторы**
   (карточка блокнота/проекта, вкладка Галереи, иконка сайдбара).
3. Готовые работы заливаются в Галерею **ТОЛЬКО вручную** (решение юзера, раунд 9):
   - виджет расширения → кнопка **«⬇ В галерею»** → перечень работ студии → клик ⬇ у нужной;
   - либо кнопка **⬇TT**, которую расширение подрисовывает у каждой работы прямо в NotebookLM.
   Автозагрузка новых работ **выключена** (была источником дублей с нестабильными именами).
4. Раскладка по типу: аудиопересказ → «Аудио», видеообзор → «Видео», инфографика →
   «Изображение», текстовые (отчёт/тест/карточки/…) → документ `.md`. Всё также в ленте
   «Hotebook» (`folder='hotebook'`). Вкладка галереи называется **«Медиафайлы»**
   (ключ таба остался `reference` — НЕ переименовывать, на него завязаны URL `?tab=reference`).

## Захват файла из NotebookLM: ТРИ механизма (все обязательны!)

Клик «Скачать» в NotebookLM ведёт себя по-разному (зависит от типа работы, версии
NotebookLM и настроек попапов браузера). `captureCardToGallery` ждёт **любой** из трёх:

1. **Blob** — `injected-nlm.js` хукает `URL.createObjectURL`: медиа-blob шлётся сразу
   (`artifact-blob` → `lastArtifact`).
2. **`window.open(подписанный URL)`** — Chrome БЛОКИРУЕТ попап без пользовательского
   жеста (наши клики синтетические!), но хук перехватывает **сам вызов** до блокировки
   (`dl-open` → `lastOpenUrl` → bg `nlm-ingest-url` → `fetchBytes` → `/observed-ingest`).
   Улика этого режима: «Всплывающее окно заблокировано» в адресной строке.
3. **Браузерная загрузка** — bg `armDownloadCapture` (взводится ДО клика, `nlm-arm-download`)
   ловит `chrome.downloads.onCreated`, отменяет загрузку (не мусорит в «Загрузках»),
   качает байты сам. Фильтр `mediaOnly` пропускает медиа И **домены Google** (подписанный
   URL не имеет ни расширения, ни mime на момент onCreated!). Разоружается через
   `nlm-disarm-download` (finally во всех путях — иначе поймает файл следующей карточки).

Для типов **без** «Скачать» (карточки/тест/ментальная карта) — фолбэк `captureCardAsText`:
открыть работу кликом → снять видимый текст → «Назад» → `.md`. Если клик увёл со
страницы блокнота — `history.back()` + abort.

## Сбор карточек работ (`studioArtifactCards`) — выученные правила

- Скан кнопок ⋮ **только внутри панели «Студия»** (`studioPanelRoot` + `withinDeep` —
  containment сквозь shadow DOM). Иначе ⋮ ИСТОЧНИКА walk-up'ом дорастал до контейнера
  со всей страницей → «карточка»-склейка источников, клик уносил на главную.
- Walk-up вверх максимум 7 уровней И **стоп на контейнерах >400 символов**.
- Настоящая карточка содержит **ровно одну ⋮** и **не содержит плеера**
  (`[role=slider]`/`input[range]`/`video`) — открытая работа-плеер не карточка.
- Заголовок чистится от лигатур Material-иконок: snake_case (`cards_star`) и plain
  (`share`+`download`→`sharedownload`, `subscriptions`), от `⬇TT`-кнопки и чипов плеера.
- Генерящиеся плейсхолдеры исключаются: `isGeneratingText` = НЕТ длительности `m:ss`
  И (маркер «вернитесь через»/«это может занять»/generating ИЛИ глагол создания
  («создаю/генераци/готовлю/…») рядом с типом работы). Формы плейсхолдеров:
  аудио — «Создаю аудиопересказ, вернитесь через несколько минут»,
  видео — «Генерация поясняющего видео. Это может занять некоторое время».

## Дедупликация

- **NotebookLM**: id = `obsId(tenant, notebookId, title)` (md5). `/observed-ingest`
  делает **атомарный клейм** (`INSERT … ON CONFLICT DO NOTHING`): кто вставил — тот
  грузит; повтор → `dedup:true` («✓ уже» в перечне). Дедуп срабатывает ТОЛЬКО если
  ассет ещё жив: удалил из галереи → перезальётся.
- **Flow**: `/ingest-manual` считает **sha256 байтов** (`flow_ext_ingest_dedup`) — клиентский
  ключ blob-видео ненадёжен (клипы одной длительности/размера).

## Индикаторы «генерится»

- NotebookLM: вотчер (20с) шлёт `nlm-observed` → upsert наблюдаемых джобов
  (`notebooklm_jobs`: `flow_id NULL`, `notebook_id` прямой, `updated_at`). Исчезнувшие
  running-строки **УДАЛЯЮТСЯ** (не `done` — иначе фантом в ✨). Отсечка свежести 2 мин
  во всех активных запросах: вкладку закрыли — спиннер гаснет сам.
- Flow: вотчер (25с) шлёт `flow-observed` → `flow_ext_observed`; GET отдаёт только
  наблюдения свежее 2 мин. Автозаливка клипов Flow ОСТАВЛЕНА (окно «недавно
  генерилось» 6 мин, переживает перезагрузку через `flowGenAt:<pid>`).

## Как менять/дополнять

- **Селекторы NotebookLM поплыли** → кнопка «разведка вёрстки» в виджете шлёт снимок
  DOM в `notebooklm_ext_recon` (смотреть `GET /api/notebooklm-ext/recon` или в БД).
  Лог виджета печатает каждый шаг захвата — по нему видно, какой из 3 механизмов молчит.
- **Новый тип работы студии** → добавить: в `ARTKIND_RE`+`detectGtype` (content-notebook),
  в `GEN_TYPES`/`RU_LABEL` и при необходимости `GTYPE_EXT`/`GTYPE_MEDIA` (ext_bridge.ts).
- **Изменить раскладку по разделам** → `GTYPE_MEDIA`/`EXT_MEDIA` в ext_bridge.ts
  (`audio`→kind audio, прочее→reference; mediaType решает вкладку-фильтр).
- **Версии — бампить ВЕЗДЕ**: `manifest.json` + `BRIDGE_VERSION` (content-bridge.js) +
  `TT_EXT_VERSION` (AppVersion.tsx) + пересобрать zip в `apps/frontend/public/`.
  ⚠ `Compress-Archive` падает на файлах, залоченных Google Drive → собирать питоном
  с ретраями чтения (см. историю: scratchpad/buildzip.py).
- **Деплой**: push в main → SSH на VPS → `vps-redeploy.sh`; фронт собирается с фолбэком
  `npm run build || npx vite build`, который МАСКИРУЕТ ошибки tsc → всегда грепать лог
  деплоя на `error TS` и гонять `tsc --noEmit` локально до пуша.

## Хроника багов (чему научились)

| # | Симптом | Причина | Фикс |
|---|---|---|---|
| 1 | Дубли/фантомы в ✨ | двойная строка `-a`, done-фантомы | один id, DELETE исчезнувших |
| 2 | Вечный спиннер | нет отсечки свежести | `updated_at` + 2 мин |
| 3 | Кнопка ⬇TT падала на карточках | у типа нет «Скачать» | текст-фолбэк `.md` |
| 4 | Аудио «не перехватил файл» (1) | плейсхолдер «Создаю…» считался готовой работой | GENERATING-исключение |
| 5 | Аудио в «Загрузки», не в Галерею | прямой URL не blob | перехват chrome.downloads |
| 6 | Захват отвергал загрузку | у onCreated нет mime/имени | google-домены в фильтр |
| 7 | `.bin` в «Видео» вместо «Аудио» | octet-stream без имени | раскладка по gtype |
| 8 | Аудио «не перехватил файл» (2) | popup-блок `window.open` | MAIN-хук на вызов window.open |
| 9 | Залилась склейка источников, унесло на главную | walk-up без потолка/скоупа | скоуп «Студии», ≤400 симв., одна ⋮ |
| 10 | 4 копии видео | открытый плеер = «карточка» с нестабильным именем | исключение плееров + ручная загрузка |
